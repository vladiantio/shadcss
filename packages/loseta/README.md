# loseta

The CLI and registry for [loseta](https://github.com/vladiantio/loseta).

```bash
npx loseta init
npx loseta add button card field
```

## Commands

| Command | Description |
| --- | --- |
| `loseta init` | Create `loseta.json`, install the foundation files and generate `index.css`. |
| `loseta add <items...>` | Install components and their registry dependencies. |
| `loseta add all` | Install every stable component. |
| `loseta list` | List stable components. |
| `loseta list --all` | Include primitives and foundation items. |

`add` flags: `--overwrite`, `--no-deps`, `--html`, `--theme`, `--yes`.
`init` flags: `--css-dir`, `--entrypoint`, `--theme`, `--import`, `--yes`.

Re-running `init` resets `.loseta/manifest.json` to the foundation and regenerates
`index.css`. Component files stay on disk but are no longer tracked; run
`loseta add all` to restore their manifest entries and imports.

## Registry layout

```
registry/
  registry.json          # item manifest
  schema.json            # JSON Schema for the manifest
  tokens.css             # design tokens
  reset.css              # minimal reset
  base.css               # element defaults
  utilities.css          # sr-only
  primitives/            # shared popover and dialog shells
  components/            # structural CSS per component
  themes/nova/           # visual CSS per component
  examples/              # example markup used by `add --html`
```

Each component item contains:

- a base file in `components/` (structure and behavior),
- a theme file in `themes/nova/` (visual style),
- optional primitive dependencies,
- a root selector list,
- optional composition metadata.

`index.css` is generated by the CLI and declares the layer order:

```css
@layer loseta.tokens, loseta.reset, loseta.base, loseta.components, loseta.theme, loseta.utilities;
```

## Development

```bash
pnpm install
pnpm --filter loseta build       # tsc -> dist/
pnpm --filter loseta test        # registry and install pipeline tests
pnpm --filter loseta validate    # registry integrity + CSS parse
pnpm --filter loseta examples    # regenerate registry/examples from the docs
pnpm --filter loseta dev         # run the CLI with tsx
```

The registry is validated for:

- schema conformance,
- file and example existence,
- dependency resolution and cycles,
- `@layer` wrapping,
- forbidden Tailwind/legacy patterns,
- CSS parseability with Lightning CSS.
